## 研究代码

围绕「因果 × 多模态 × 可靠性」主线的论文配套代码：

| 仓库 | 说明 |
| --- | --- |
| [CogCal-VAD](https://github.com/ming616/CogCal-VAD) | 因果启发式认知校准的目标域零适配视频异常检测 |
| [FCD-Net](https://github.com/ming616/FCD-Net) | 因果去偏与结构化中介建模的少样本视频异常检测 |
| [InferenceCausal](https://github.com/ming616/InferenceCausal) | 多模态信息抽取的推理时证据一致性验证 |
| [CausalConsistencyDomainAdaption](https://github.com/ming616/CausalConsistencyDomainAdaption) | 因果一致性域适应，抑制捷径学习 |
| [MinimalResource](https://github.com/ming616/MinimalResource) | 反事实模型感知数据价值评估（CF-MAV） |

各仓库包含论文 LaTeX 源码、模型实现与实验脚本，可作为方法复现的起点。
